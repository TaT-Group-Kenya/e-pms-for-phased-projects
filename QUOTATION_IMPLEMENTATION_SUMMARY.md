- **Params:** `id`
- **Purpose:** Fetch detailed view of a specific quotation

## 4. Data Flow & Field Mapping

### Quotation Fields (from Laravel Model):
```
- quotation_number (auto-generated)
- title (required)
- description (optional)
- status (draft, sent, approved, rejected, revised)
- customer_id (required)
- project_id (optional - for linking to projects)
- valid_until_date (required)
- currency (required)
- subtotal_amount (auto-calculated)
- tax_percentage (user input)
- tax_amount (auto-calculated)
- discount_percentage (user input)
- discount_amount (auto-calculated)
- total_amount (auto-calculated)
- payment_terms (optional)
- notes_to_customer (optional)
- min_approval_count (default: 1)
```

### Form Validation Rules:
- Title: Required, max 255 chars
- Customer: Required selection
- Valid Until: Required, min date = today
- Currency: Required selection
- Tax %: 0-100, optional, defaults to 0
- Discount %: 0-100, optional, defaults to 0
- All text fields: Max 255-1000 characters, optional

## 6. Features & Workflow

### Quotation Lifecycle:
1. **Create** → Status: Draft (quotation created but not yet sent)
2. **Add Items** → Items table (future enhancement)
3. **Mark as Sent** → Status: Sent (ready for customer review)
4. **Approval** → Status: Approved/Rejected/Revised
5. **Convert to Order** → Status: Approved (can be converted to actual order)

### Key Workflow Notes:
- ✅ Quotations start as **Draft**
- ✅ Can only be marked as **Sent** after items are added (backend validates)
- ✅ Quotation numbers auto-generated by Laravel backend
- ✅ Amounts auto-calculated server-side
- ✅ Only draft quotations can be deleted
- ✅ Search and filter available on list page
- ✅ Reports dashboard provides business insights
