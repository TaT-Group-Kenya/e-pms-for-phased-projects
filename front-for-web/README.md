# front-for-web (Next.js sign-in)

Minimal Next.js app with a sign-in page styled to resemble the provided template.

Getting started

1. Install dependencies:

```bash
cd front-for-web
npm install
```

2. Run dev server:

```bash
npm run dev
```

Open http://localhost:3000 to view the sign-in page.

Tailwind CSS

This project is pre-configured for Tailwind CSS (PostCSS + Autoprefixer).

After running `npm install`, Tailwind will be available and the global styles
are included from `styles/globals.css`.

If you need to re-generate the Tailwind config locally, run:

```bash
npx tailwindcss init -p
```
